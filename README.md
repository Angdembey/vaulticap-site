# VaultItem website

Public marketing, user guide, support, and privacy pages for VaultItem on iPhone and iPad.

- Repository: https://github.com/Angdembey/vaultitem-site
- GitHub Pages: https://angdembey.github.io/vaultitem-site/
- Home: https://angdembey.github.io/vaultitem-site/
- User guide: https://angdembey.github.io/vaultitem-site/guide/
- Support: https://angdembey.github.io/vaultitem-site/support/
- Privacy: https://angdembey.github.io/vaultitem-site/privacy/

GitHub Pages publishes the `docs/` directory from `main`. Website content uses the VaultItem name and reflects the current app workflows, including the app-wide Face ID or device-passcode lock and the separate Private Secure Vault authentication.

The app is available on iPhone and iPad. Support: angdembey.dra@gmail.com.
